# Trainee_2026_
# 🐋 Trainee Program 2026: Cá voi bơi (1 sản phẩm vibe code zui zui)

## ✨ Có gì hay ho?

- 🐳 **Cá voi bơi chân thật:** ảnh được cắt thành hàng chục dải dọc, mỗi dải uốn theo sóng sin chạy dọc thân
- 💫 **Idle mượt mà:** cá voi vẫn bơi tại chỗ nhẹ nhàng sau khi vào vị trí.
- 📱 **Responsive** cho desktop, tablet và mobile..
- 📦 **0 thư viện**, chỉ HTML + CSS + JS thuần.

## 🚀 Chạy thử 

1. Tải/clone project về.
2. Mở thư mục bằng **VS Code** → chuột phải `index.html` → **Open with Live Server**.
   *(Hoặc mở thẳng `index.html` bằng trình duyệt, nhưng Live Server sẽ ổn định hơn.)*
3. Ngồi xem cá voi bơi 🍿
